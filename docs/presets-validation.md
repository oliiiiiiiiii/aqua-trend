驗收條件：至少一個**預設資料層**的事件平均 z 滿足 |z| ≥ 2，且方向與 `expected` 一致。三個事件都通過。

**交叉驗證待辦**：工作線 A 的 `analysis.ts` 尚未合併。A 完成後，要用 `decompose` + `intervalStats` 對同樣的事件再算一次，`meanResidual`、`meanZ` 與下表差異應 < 1%。差異較大時，先比對下方「方法」中的細節（季節循環的合格年份規則、σ 的自由度、趨勢與季節循環是否交替擬合）。

## 方法

依 INTEGRATION.md 工作線 A 的規則，以 Python + numpy 重寫：

1. **基準期** = 該資料層全部月份，扣除 `[event.start − pad, event.end + pad]`（pad = 12），再扣除缺值月。
2. **趨勢與季節循環只用基準期擬合**：線性趨勢（OLS，對月序號）與 12 個月氣候值交替擬合到收斂（先用去季節值擬合趨勢，再用去趨勢值求各月平均；氣候值減去 12 個月平均，讓截距由趨勢吸收）。
3. **季節循環的合格年份**：某個日曆年的缺值月數 > 3 時，該年不參與氣候值。缺值月 = 該年基準期內的 `null`，加上落在資料紀錄以外的月份（例如紀錄始於 2000-02，則 2000 年缺 1 個月）。被事件窗排除的月份**不算缺值**。
4. **殘差** `r = x − 趨勢 − 季節`；`σ` = 基準期殘差的樣本標準差（ddof = 1）；`z = r / σ`。
5. **事件統計**：事件期間有值月份的平均殘差與平均 z。`null` 一律保持 `null`，不補值、不當 0。
6. **名次**：全期間所有同長度、無缺值的滑動區間平均殘差排序，方向依事件平均殘差的正負（對應 `IntervalStats.rank`）。
