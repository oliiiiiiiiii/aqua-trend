## 方法

依 A 的 `web/lib/detective/analysis.ts`，以 Python + numpy 獨立計算：

1. **基準期** = 該資料層全部月份，扣除 `[event.start − pad, event.end + pad]`（pad = 12），再扣除缺值月。
2. **季節循環的合格年份**：以事件排除前的原始紀錄計數；一個日曆年至少有 9 個有值月才合格。原始缺值與落在紀錄外的月份皆算缺值；事件排除本身不會降低原始有值月數。
3. **趨勢與季節循環只用基準期擬合**：先在合格年份的基準期，以「時間 + 月份效應」聯合 OLS 求出 12 個月季節循環，並使其平均為 0；再固定季節循環，以全部有值基準期月份重擬線性趨勢。缺值過多的年份仍可參與第二步趨勢估計。
4. **殘差** `r = x − 趨勢 − 季節`；`σ` = 基準期殘差的樣本標準差（ddof = 1）；`z = r / σ`。σ 為 0 時 z 缺值。
5. **事件統計**：事件期間有值月份的平均殘差與平均 z。`null` 一律保持缺值，不補值、不當 0。
6. **名次**：全期間所有同日曆長度、無缺值的滑動區間平均殘差排序，方向依事件平均殘差的正負；事件本身也納入。事件缺月時不排名。並列容差與 A 一樣，按區間值的大小乘浮點精度計算。
