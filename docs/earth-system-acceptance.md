# Aqua Trend 驗收規格

本文件是 [系統技術規格](earth-system-trend-detective-spec.md) 的完成判準。測試輸入與欄位以 [資料與 API 契約](earth-system-data-contracts.md) 為準。本文件列出未來實作必須通過的驗收，不宣稱程式或測試已完成。

## 1. 驗收分層

| 層次 | 驗證目的 |
| --- | --- |
| 契約與政策 | 只接受既有 ID、正確資料型態與來源；規則可重現。 |
| 科學數值 | 已知案例、可信參考實作及模擬檢查，涵蓋斜率、季節性、時間相依、缺值及校正。 |
| 整合 | 同一工作計畫經 API、引擎、圖表與匯出後一致。 |
| 使用者流程 | 結構化單區／期間、preset 補值、查詢及重新分析、所有缺資料與錯誤分支。 |
| 真實資料 | 使用團隊補交的已備資料，核對來源、標準定義、數值及涵蓋。 |

單元測試可使用明確標示的測試序列及事件。它們只能作測試，正式畫面不以合成數字冒充 NASA 資料或觀測事件。

## 2. 輸入及 preset 四種組合

| 案例 | 操作 | 必須觀察到的結果 |
| --- | --- | --- |
| P01 | 輸入現象，區域與期間皆空 | 產生合法 variable set；補入一個既有區域及期間，兩者標記 preset，顯示理由。 |
| P02 | 現象加使用者單區，期間空 | 區域 ID 與邊界完全不變；只推薦期間。 |
| P03 | 現象加使用者期間，區域空 | 起訖完全不變；只推薦一個既有區域。 |
| P04 | 現象、單區與期間皆填 | 原條件直接分析；preset 不替換任何值。 |
| P05 | 已填條件沒有合格 preset | 回傳 no_matching_preset 及原因；保留已填值，不自動改區或延長期間。 |
| P06 | 人工釘選案例與使用者條件衝突 | 不套用該案例；人工設定不能蓋掉已填條件。 |
| P07 | 新現象輸入但原欄位來源不同 | 手選欄位保留；preset 欄位按已登錄規則重新推薦，來源保持正確。 |
| P08 | 相同輸入、資料及政策版本重跑 | 預設重用已保存 selection plan，數值依該計畫在容許誤差內一致；明確新模型選擇產生新 plan ID，不要求不同模型呼叫逐項相同。 |
| P09 | 從 preset 開啟再調整 | 後端能從 preset／父研究引用還原欄位來源與搜尋證據；衝突引用不覆寫 user 條件，不能信任前端自填校正數字。 |

## 3. 自然語言與選擇計畫

| 案例 | 必須通過的條件 |
| --- | --- |
| S01 既有變數 | 所有模型輸出的概念及配方 ID 都存在於當次離線目錄。 |
| S02 任意現象 | 中文／英文及非固定範例的現象能交由同一選擇流程處理；不依只含乾旱／淹水的硬編碼清單決定能否輸入。 |
| S03 適用範圍 | 沒有有依據的變數時明確 unsupported，不加入無關變數；有部分資料時清楚區分可回答與不可回答部分。 |
| S04 角色 | 分類與理由可指回離線說明；圖表中的趨勢不被當成角色已證實的因果證據。 |
| S05 地點／時間文字 | 文字包含地名或日期時，結構化欄位不被模型設定或覆寫；畫面說明實際採用的條件。 |
| S06 非法輸出 | 模型回傳不存在的 ID、任意程式碼或新的事件公式時，不執行、不保存成合法計畫。 |
| S07 服務失敗 | 模型未設定／不可用時，保留輸入與可重試狀態；不把示範選擇冒稱模型成功。 |

## 4. 區域、產品與期間

| 案例 | 必須通過的條件 |
| --- | --- |
| D01 單區 | 請求及結果只含一個研究區域；地球與清單定位相同既有 ID 及幾何。 |
| D02 有邊界但無序列 | 顯示資料不足；不以父區、鄰近格點或其他區域數值冒充。 |
| D03 主產品適用 | 使用該概念主要產品，整段序列來源一致。 |
| D04 備選回退 | 主產品不適用時按核可優先序選備選，公開來源及原因；不以較大斜率或較小 p 值選產品。 |
| D05 定義不同 | 相同 category 但不同物理量／深度不能互相備選。 |
| D06 所有產品不足 | 變數保持可見，原因清楚；使用者區域與期間不改。 |
| D07 共同期間 | 主比較的期間及變數資格明確；完整歷史另外可看，不把各自不同期間當成同段比較。 |
| D08 指定期間不完整 | 顯示 requested、actual support 及不足；不默默縮短後當完整答案。 |
| D09 缺值與零 | 缺月保持空值及真實時間位置，零值照實呈現；圖表斷線及樣本數正確。 |
| D10 指標不適用但變數可用 | 指標校準不足時保留可支持的變數趨勢及來源，指標獨立標不足；不把兩項一起抹去。 |

## 5. 趨勢與統計

| 案例 | 驗證方式與預期 |
| --- | --- |
| T01 已知斜率 | 使用已知線性斜率加固定季節項的測試序列，核對去季節後斜率、單位與每十年換算。 |
| T02 固定基準 | 同資料改動分析期間，月份參考值與基準版本不變；只改擬合結果。 |
| T03 保留趨勢 | 季節處理不先移除長期斜率；可回復原始值與距平的關係。 |
| T04 時間座標 | 刪缺值不壓縮日曆距離；不規則缺口案例與正確時間座標的參考結果一致。 |
| T05 自相關 | 對預先設計的時間相依測試資料及參考實作核對不確定性；適用性不成立時拒絕推論而保留描述性結果。 |
| T06 常數／短期 | 常數、過短、過少或集中缺值資料不產生 NaN／Infinity 或假的顯著標記。 |
| T07 基準不足 | 不默默用查詢期重算常態，也不把較短平均當完整標準常態。 |
| T08 家族校正 | 已知 p 值集合與可信 BY 參考實作一致；原始 p 值不被覆寫。 |
| T09 完整家族 | 確認未顯著、未入選的有效檢定仍納入校正；不適用項目保留原因。 |
| T10 預先宣告 | Preset 候選政策及實際搜尋清單可查，未完成整批校正前不發布最終標記。 |
| T11 選擇脈絡 | 開啟 preset 後保留其搜尋校正，不能改以單一案例的較小家族取代。 |
| T12 CI 範圍 | 畫面與匯出明示 pointwise CI；不能因 p 值校正就宣稱 CI 已同時／選擇後校正。 |
| T13 百分比 | 攝氏、距平及近零平均量不顯示無意義百分比。 |
| T14 校準 | 用已登錄的無趨勢、季節性、時間相依及缺值情境模擬評估誤報與覆蓋；記錄假設與容許範圍。單次漂亮圖例不能代替這項驗證。 |
| T15 Metric 識別 | 同配方、同區同期間的頻率及持續時間各有 hypothesis ID，家族不低估檢定數。 |
| T16 版本匹配 | 更新資料、區域幾何、配方或基準後，舊 preset 校正不能套到新數值；歷史結果及來源仍可查。 |

## 6. 事件與標準指標

| 案例 | 必須通過的條件 |
| --- | --- |
| E01 標準定義 | 指標有來源、公式、版本、門檻與適用條件；AI 只能選已核可配方。 |
| E02 實際事件 | 頻率及嚴重度能追到事件紀錄、資料來源與涵蓋版本。 |
| E03 標準推算 | 推算指標能追到輸入產品與科學配方，清楚標記 derived_indicator。 |
| E04 未補事件資料 | 結果為 data_required，不產生「零次事件」或虛構時間線；其他可分析變數正常呈現。 |
| E05 完整涵蓋下零事件 | 只有已聲明完整的空白期間可填零；partial／unknown 不填零。 |
| E06 邊界與缺口 | 跨查詢邊界事件不被切成重複事件；持續時間的截尾與缺口處理符合固定規則。 |
| E07 年度聚合 | 計次歸屬、不完整年度及事件曝露／涵蓋依配方處理；年度結果不再套月季節調整。 |
| E08 降水量綱 | SPI 等累積量配方對 mm/day 月平均率按實際日數轉月總量，缺月不視為零雨量。 |
| E09 基準與尺度 | SPI-3／6／12 等尺度及固定擬合期分別驗證；不得以查詢窗口重新擬合。 |
| E10 現象限制 | 月降水異常不能標成實際洪水頻率；沒有適用標準或解析度時，現象指標明確 not_applicable／不足。 |
| E11 粗時間精度 | 只有年份／月份的紀錄不被填入虛構精確日期；事件歸屬及持續時間依不確定區間與規則處理。 |
| E12 多目錄重複 | 選定單一核可事件目錄，或使用已備 canonical_event_id 去重；重複報導不重複計次。 |

## 7. Preset 評分與人工調整

- 不同單位的斜率使用已定義的尺度比較，常數基準不除以零。
- 未顯著案例仍可取得有效興趣分數與推薦位置，並明示不確定性。
- 相關性、效應、品質、穩定性及聚合規則的版本可追蹤，新增變數不會因數量本身自動增加總分。
- 人工設定能新增／釘選、調整及停用；不改科學數字、有效性或已填條件。
- 未完成或部分搜尋不標記完整；失敗、排除與未檢定候選可查。
- 相同資料與政策的自動結果可重現，來源更新後建立新版本。

## 8. 前端與端到端

- 地圖、清單及鍵盤皆能選同一套既有單區，手機可完成完整流程。
- 期間選擇 optional；起訖不合法有可理解錯誤且保留輸入。
- 在 time series 套用新期間後，驗證後端重算斜率、CI、事件／指標與查詢校正；不是僅改播放或縮放。
- 原始完整歷史、固定季節型態、去季節序列及分析範圍標記均可查看。
- 來源切換、涵蓋、固定參考期與觀測／推算標記能在相應結果旁查到。
- 圖表、文字、數值表格與 JSON／CSV 對同一研究快照一致。
- 後端不可用、解析失敗、無匹配、缺基準、缺事件、部分完成與取消均有可讀狀態及合適重試行為。
- 較舊工作回應不覆蓋最新使用者條件；錯誤與重試保留已填欄位。
- 圖表有數值替代，主要狀態不只用顏色，文字可讀；動畫可暫停及減少。
- 正式結果不包含舊 synthetic leads，示意地景與有資料支持的視覺通道明確區分。

## 9. 完成紀錄

交付時逐項列出「已通過／未通過／待資料」。程式契約通過與真實科學數值通過分開記錄。

最低完成證據為：可運行的前後端、全流程測試、科學數值及校正核對、preset 與手選條件測試、事件待補行為、來源及版本紀錄、響應式與可及性檢查、同一計畫重現。待補事件資料不得被隱藏，也不應阻止其他有資料功能完成。
