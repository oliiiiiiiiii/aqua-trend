# UX audit: site shell, home, Explore, content pages (excludes the `/detective` analysis screen)

Audited 2026-11-15 on branch `ui/ux-refresh` against the dev server. Screenshots (in
`/tmp/claude-1000/-home-rainple-aqua-trend/16af4599-9471-476e-a152-94ffab7c00d6/scratchpad/audit/`): `home.png`, `home-m.png`,
`det.png`, `det-m.png`, `det-night.png`, `det-tab.png`, `exp.png`, `exp-m.png`, `conc.png`, `dev.png`, `data.png`, `nf.png`, `meth-m.png`.

## Summary

1. The home page sells the old product: hero headline, primary button, three-step explainer, "what is real" and featured regions all describe Explore; Detective is one small underlined link (`app/page.tsx:50-57`). A judge with 2 minutes never learns the main flow exists.
2. Data, Methods, footer, `<meta description>` and 404 still describe a GLDAS-only, water-cycle demo with synthetic leads. Nothing on Data or Methods explains anomaly, baseline, z-score, significance or the other products Detective uses.
3. Dev harnesses (`/dev/*`) and the "UI directions" page (`/concepts`) are live public routes; `/dev/orb` renders a full test UI at the same chrome as the product.
4. Contrast: white and pale-blue text on the lower half of the light "sky" gradient is 2.6 to 2.9:1; the on-stage tiny text fails AA in the terrarium theme.
5. Terminology and language drift: Chinese examples in the English Detective input, "Trend Detective" vs "Detective" vs "Explore", "region / basin / sub-basin / boundary" used interchangeably, 216 MB `public/data` with a decorative WebGL globe on the home page.

## Improvement plan

Before the demo (about a day):
- A1, A2: make the home page about Detective, with a one-click example case. This is the single largest gain.
- A4, A5: gate `/dev/*` and `/concepts` in production, fix the duplicate `<main>`.
- A6, A7, A19: document every dataset and the Detective statistics on Data and Methods; this is what a scientific judge checks.
- A11, A12: darken the sky gradient end and fix the disabled button.
- A9, A8, A18: update metadata and share image, put credits and the "timing, not cause" line in the main flow.

After the demo:
- A3, A16, A23: settle product naming and demote or merge Explore.
- A20, A24: lighter first paint, error and no-WebGL states.
- A14, A15, A22, A21, A25, A26: mobile globe placement, copy and accessibility polish.
- A10, A17: small copy fixes.


## Analysis features to add in the browser (from `docs/backend-tools.md` §3)

These need no server and fit the redesigned workbench:
- Scan all 34 layers of the basin and rank by |mean z| for the current selection ("What else was unusual?").
- Lead/lag scan: slide the selection ±12 months and show where the anomaly peaks (with a multiple-testing warning).
- Benjamini–Hochberg q values beside p when several lanes are compared.
- Block-bootstrap / AR(1)-surrogate p values in a Web Worker as a robustness check.
- Climate indices (Niño 3.4, IOD, SAM) as context lanes, added to the data bundle by pipeline F.
