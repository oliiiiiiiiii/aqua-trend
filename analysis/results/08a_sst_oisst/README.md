# Task 08a — Sea surface temperature trends, NOAA OISST v2.1 monthly 0.25°, 1982-01 → 2026-10

- **81 % of the ice-free ocean** warmed significantly (both tests, FDR). Global 60°S–60°N: **+0.19 ± 0.04 °C/decade**.
- Around Taiwan: **Taiwan Strait +0.33 ± 0.07 °C/decade**, East China Sea +0.31, Kuroshio east of Taiwan +0.24, northern South China Sea +0.26 (all p < 1e-14).
- Faster: Sea of Japan +0.45, Gulf of Maine/NW Atlantic +0.45, Mediterranean +0.39 °C/decade.
- "Hot months" (anomaly above the 1982–2011 90th percentile): Taiwan Strait 0.1 → **5.0 per year** (1982–91 → 2016–25); East China Sea 0.1 → 6.5; Mediterranean 0.3 → 10; global 0 → 12 (i.e., every month now beats the old top-10 %).
