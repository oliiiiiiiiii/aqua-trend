# Task 08c — Marine heatwaves around Taiwan & East Asia, NOAA OISST daily 0.25°, 1982-01 → 2026-11

**Definition:** Hobday et al. (2016): SST above the day-of-year 90th percentile (1983–2012 baseline, 11-day window) for ≥ 5 consecutive days (no gap merging → conservative). Fixed baseline, so the count includes the effect of long-term warming (standard practice). Regional MHW day = ≥ 50 % of the region's ocean area in a heatwave.
